# E2E Test Infra: HERMES // OS (Personal Life Manager)

> **✅ E2E HARNESS SAFETY (`E2E-S`, commit `027fcc6`) — SAFE BY DEFAULT:**
> - **Per-Run Temp Fixtures (`R1`)**: Every live and static mode of the suite (`node e2e/run-e2e.mjs`, `--tier N`, or direct Playwright with `e2e/playwright.config.ts`) automatically allocates a per-run temporary fixture root `<os.tmpdir()>/hermes-e2e-run-<pid>-<rand>` (`E2E_RUN_FIXTURE_ROOT`) containing `${E2E_RUN_FIXTURE_ROOT}/vault` (`E2E_SECOND_BRAIN_DIR`), `${E2E_RUN_FIXTURE_ROOT}/youtube-lists.sqlite` (`E2E_YOUTUBE_LISTS_DB`), and `${E2E_RUN_FIXTURE_ROOT}/yt-notes` (`E2E_YOUTUBE_LISTS_NOTES_DIR`), and cleans it up automatically on exit. Plain `SECOND_BRAIN_DIR`, `YOUTUBE_LISTS_DB`, and `YOUTUBE_LISTS_NOTES_DIR` in the caller environment are ignored whenever they point into `<repo>/data/`, any protected root, or outside `os.tmpdir()`.
> - **Hard `<repo>/data/` Guard (`R2`)**: `assertSafeE2eDataPath()` hard-blocks any path resolving inside `<repo>/data/` or any additive protected root (after canonicalizing symlinks, dangling symlinks, missing leaves, and relative segments without `stat`ing `<repo>/data/`) with `[E2E-SAFETY-GUARD]` before starting or contacting any server.
> - **No Blind Server Reuse (`R3`)**: By default (`E2E_ALLOW_EXTERNAL_SERVER=false`), `ensureStackReady()` refuses to reuse any pre-existing listener on `127.0.0.1:8080` whose `${E2E_RUN_FIXTURE_ROOT}/managed-server.json` and `/proc/<pid>/environ` `HERMES_E2E_SERVER_TOKEN` + safe temp data paths were not created by the current run.
> - **Confined Vault Cleanup (`R4`)**: `snapshotSecondBrainFiles()` and `cleanupNewSecondBrainFiles()` require a harness-owned temp vault marker (`.hermes-e2e-vault-root`) inside `os.tmpdir()`, only delete files and harness-created subdirectories added after the snapshot, preserve pre-existing directories and `.git`/`.obsidian`, and never traverse symlinks.
> - **All 51 `e2e/` Files Tracked (`R6`) & Full Suite Intact (`R7`–`R8`)**: `e2e/tests/tier2/area-d-sync-and-prod.spec.ts` assembles its synthetic secret-hook test fixture at runtime (`git ls-files e2e/` = `51` files), `452` tests across `31` `.spec.ts` files pass `--dry-check`, and `node e2e/run-e2e.mjs --self-test` verifies `R1`–`R5` against stand-in temporary directories.
