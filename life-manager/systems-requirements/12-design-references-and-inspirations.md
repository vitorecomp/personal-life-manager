## 2. Brand Identity, Loaders & Motion Hierarchy (`REF-09` – `REF-12`)

### 2.1. System Logo Mark (`REF-10` — *The Second Brain Aperture*)
- Rendered as a crisp layered inline `<svg>` in the top-left app bar, browser favicon, and mobile app icon:
  1. **Outer Gunmetal Reticle**: Fine segmented telemetry ticks (`#2A2D35` / `#8A909E`).
  2. **Blaze-Orange Gear Ring**: 36-tooth industrial ring (`#F87C18`, echoing `REF-02`).
  3. **Stark-White 8-Blade Mechanical Shutter**: Interlocking geometric aperture blades (`#F6F6F4`) that subtly contract/dilate (`transform: rotate(...)`) when Hermes or an Agent Knight is actively thinking!
  4. **Inner Phosphor Core**: Glowing `#A8F040` / `#F4F6C2` iris ring signaling `BACKEND_ONLINE` (shifts to amber when offline/syncing).

### 2.2. Three-Tier Loading & Motion System
1. **Tier 1 — Cold Boot / Auth Hydration (`REF-09`)**: Full-viewport 3D-tilted Blaze-Orange Orbital Astrolabe (`◆◆` diamond core + live `[1..3]` Rust subsystem stage tag).
2. **Tier 2 — Panel / Async Data Operations (`REF-11`)**: Modular monochrome radial HUD spinners (*sonar array*, *vector rotor*, *proximity scan* built from `REF-10` & `REF-11` concentric SVG arcs) with live ms/row counters during CSV imports, Vault indexing, or Blueprint generation.
3. **Tier 3 — Button & Status Micro-Animations (`REF-12`)**: Crisp `16×16` / `20×20` stark-white stroke animations inside `0px` dark square badges:
   - **Focus Timer active**: Pendulum / sweeping clock or flipping hourglass (`TIME` row).
   - **Server Prober & SSE stream**: Radiating tower pulse (`WIFI` row).
   - **Vault RAG / Course study**: Flipping open grimoire/book pages (`ICONS` row).
   - **Inline LLM wait**: 3-dot orbital triangle rotation (`DOTS` row).

## 3. Core FUI Design Laws (`REF-02` Primary Anchor)

1. **Strict `0px` Rectilinear Framing**: Sharp `90°` corners everywhere; stepped `1px` + `4px` horizontal top rules (`GLOBAL_LAYOUT` / `PROTOCOL_DIAGNOSIS`); `[+]` solid `#F87C18` square prefix badges; diagonal `45°` hazard hatch fills (`/////`).
2. **Three-Tier Typography**:
   - **Display Numerals & Module Titles**: `Barlow Condensed` / `DIN Condensed` (`SAT.3`, `DB.40`, `89`, `tabular-nums`).
   - **Technical Labels, Blueprints & Ledger**: `JetBrains Mono` / `IBM Plex Mono` (`>= 12px` floor on interactive UI, underscore slugs `PROTOCOL_DIAGNOSIS`).
   - **Long-Form Reading & Chat Prose**: `IBM Plex Sans` / `Inter` (`#E4E6EB`).
3. **Unified Palette**:
   - **Canvas**: Pitch Carbon `#08080B` (`REF-02`), Tactical Plum `#0D0716` (`REF-01`), Blueprint Slate `#10171D` (`REF-03`), Elevated Panel `#13151A`.
   - **Accents**: Blaze Orange `#F87C18` (primary), Vermilion `#EB4511` (alerts/beacons), Amber `#F59E0B` (row tabs), Phosphor Cream `#F4F6C2` (callout headers), Flow/Mana Cyan `#2CE5F2` (active paths, `REF-08` Thinking Orb, and Frieren magic).

## 4. Character & Isometric World Cohesion (`REF-13` & `REF-14`)

The pixel-art fantasy layer follows one cohesive internal lore across the FUI OS:
- **Arch-Mage Companion (`06` — Frieren × `REF-14`)**:
  - **Mini-Sprite**: Walks and sits along `REF-02`'s `3px` orange panel ledges across every screen (Clippy-style screen presence, integer `2x/3x` `image-rendering: pixelated`).
  - **Waist-Up Chat Portrait (`REF-14`)**: Inside the `Cmd+J` popover and idle night card, animates with `REF-14`'s **calm half-lidded downward gaze, slow blink + gentle head-tilt cycle, asynchronous wind-blown silver twin-tails & *ahoge*, and `+` starlight glints**.
- **Order of Isometric Knights (`05` — Agent Studio × `REF-13`)**:
  - Entering **Agent Studio** reveals an isometric tactical grid floating over dark FUI circuit traces where each autonomous agent stands as an armored **Pixel-Art Knight** (`Paladin`, `Vanguard`, `Lore-Warden`, `Inquisitor`), complete with a top initiative queue bar, `HP` (budget quota) / `EP` (token load) bars, and bottom 4-slot tool/skill HUD!

## 5. Locked Brand & Asset Pipeline Decisions

- **System Header & Brand Identity**: **`HERMES // OS`** paired with the `REF-10` layered SVG Mechanical Aperture Logo.
- **3D / Geometric Rendering**: Lightweight **Canvas2D / SVG + CSS 3D transforms** for the `REF-08` Geodesic Thinking Orb and `REF-09` Orbital Boot Astrolabe (instant 60fps startup, zero heavy WebGL bloat).
- **Hot-Swappable Pixel-Art Sprite Pipeline**: Build `<CompanionStage />` (Frieren `REF-14`) and the Isometric Knight Board (`REF-13`) around standard **`PNG + JSON` sprite-sheet descriptors**—shipping day-1 functional pixel sprite sheets that can be hot-swapped with custom Aseprite artwork anytime with zero code changes.
